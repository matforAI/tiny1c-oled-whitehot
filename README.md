# Tiny1-C OLED White Hot

Tiny1-C thermal image on Waveshare 0.95-inch RGB OLED (96x64).
White Hot: hot areas are white, cold areas are black.

## Installation

On a clean Raspberry Pi OS, install Git first, then clone the repository and run the installer:

```bash
sudo apt update && sudo apt install -y git
git clone https://github.com/matforAI/tiny1c-oled-whitehot.git
cd tiny1c-oled-whitehot
sudo bash install.sh
```

The installer enables the systemd service for automatic startup.
